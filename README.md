# md2gost

**Русский** | [English](README.en.md)

Настольное приложение, которое превращает Markdown в документ Word (`.docx`),
оформленный по **ГОСТ 7.32-2017** («Отчёт о научно-исследовательской работе»).
Пишете текст в обычном Markdown — получаете готовый отчёт с правильными полями,
шрифтами, нумерацией разделов, рисунков, таблиц и формул, оглавлением,
списком литературы и титульным листом.

Под капотом — [pandoc](https://pandoc.org) и
[pandoc-crossref](https://github.com/lierdakil/pandoc-crossref); программа
сама скачивает и настраивает их при первом запуске.

---

## Возможности

- **Оформление по ГОСТ 7.32-2017**: A4, поля 30/15/20/20 мм, Times New Roman 14 пт,
  интервал 1,5, абзацный отступ 1,25 см, номера страниц внизу по центру.
- **Нумерация разделов** `1`, `1.1`, `1.1.1` — автоматически (можно отключить).
- **Подписи и ссылки**: «Рисунок 1.1 — …», «Таблица 1.1 — …», номера формул
  справа в скобках; ссылки `@fig:…`, `@tbl:…`, `@eq:…` превращаются в номера.
- **Список литературы** из `.bib` по ГОСТ Р 7.0.5-2008 (числовые ссылки `[1]`).
- **Автоматическое оглавление** (TOC).
- **Титульный лист** из любого `.docx`: он присоединяется перед текстом, его
  стили не смешиваются со стилями отчёта и не попадают в оглавление.
- **Диаграммы прямо в тексте**: блок `<diagram>` с кодом matplotlib
  рендерится в PNG и вставляется как обычный рисунок.
- **Профили оформления**: можно добавить свой стандарт рядом с ГОСТ 7.32-2017.
- **Инструкция для ИИ**: готовый промпт, по которому ChatGPT/Claude и т. п.
  пишут Markdown сразу в нужном формате.
- Работает на **Windows, macOS и Linux**.

## Требования

| Компонент | Версия | Примечание |
|---|---|---|
| Python | **3.10+** | В более старых версиях программа не запустится |
| Tkinter | входит в Python | В Linux ставится отдельно: `sudo apt install python3-tk` |
| pandoc | 3.9+ | Устанавливается автоматически в папку `bin/` |
| pandoc-crossref | под вашу версию pandoc | Устанавливается автоматически в папку `bin/` |
| Интернет | только при первом запуске | Нужен для загрузки pandoc с GitHub |

## Установка

### 1. Скачайте проект

```bash
git clone https://github.com/<user>/md2gost.git
cd md2gost
```

Или скачайте ZIP-архив репозитория и распакуйте его.

### 2. Создайте виртуальное окружение и установите зависимости

**Windows (PowerShell / CMD):**

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Запустите

```bash
python main.py
```

При первом запуске программа проверит pandoc и pandoc-crossref. Если их нет
или версия не подходит, она скачает совместимую пару с GitHub в папку `bin/`
(около 40 МБ). Прогресс виден в строке состояния внизу окна. Системный
pandoc при этом не меняется.

### Ручная установка pandoc (необязательно)

Установщик можно запустить отдельно из консоли:

```bash
python tools/install_pandoc.py            # интерактивный режим
python tools/install_pandoc.py --auto     # без вопросов
python tools/install_pandoc.py --check    # проверить установку (код 0 — всё в порядке)
python tools/install_pandoc.py --list     # доступные версии и совместимость
python tools/install_pandoc.py --upgrade  # поставить последнюю совместимую пару
python tools/install_pandoc.py --pandoc 3.9  # конкретная версия pandoc
```

Если GitHub отвечает «превышен лимит запросов», задайте переменную окружения
`GITHUB_TOKEN` с личным токеном GitHub.

## Как пользоваться

1. **Markdown (.md)** — выберите файл с текстом отчёта.
2. **.bib файл** — необязательно; файл с библиографией BibTeX.
3. **Титульный лист** — выберите шаблон из списка или нажмите кнопку
   добавления и укажите свой `.docx`: он скопируется в `resources/titles/`
   и будет доступен и в следующий раз. «Не использовать» — без титульного листа.
4. **Стили тела** — профиль оформления (по умолчанию «ГОСТ 7.32-2017»).
5. Флажки:
   - **Авто-оглавление (TOC)** — вставить «Содержание»;
   - **Нумерация разделов** — проставить номера `1`, `1.1`, `1.1.1`.
6. Нажмите **«КОНВЕРТИРОВАТЬ»**, выберите, куда сохранить `.docx`.
7. Следите за журналом внизу окна: там будут предупреждения (нет подписи у
   рисунка, нет цитат при подключённом `.bib` и т. д.). По окончании программа
   предложит открыть готовый файл.

Кнопка **«Отмена»** останавливает конвертацию вместе с pandoc и
рендерингом диаграмм.

> При первом открытии Word может предложить обновить поля — согласитесь.
> Если номера страниц в оглавлении не появились, нажмите `Ctrl+A`, затем `F9`.

## Использование с нейросетью

1. Отдайте ИИ-ассистенту файл
   `resources/styles/GOST_7.32-2017/GOST_7.32-2017.ai.md` как инструкцию
   (а для диаграмм ещё `resources/prompts/diagram.md`).
2. Попросите написать отчёт на нужную тему.
3. Сохраните ответ в `.md` и сконвертируйте его в md2gost.

---


## Свой профиль оформления

Каждый профиль — папка в `resources/styles/` с файлом `config.cfg` и
эталонным `reference.docx`; дополнительно можно подключить Lua-фильтр,
настройки pandoc-crossref, стиль CSL и аргументы pandoc. Подробности — в
[`resources/styles/README.md`](resources/styles/README.md).
