# Профили стилей ГОСТ

В этой папке хранятся профили оформления для конвертации Markdown в DOCX.
Каждый профиль — отдельная папка непосредственно внутри `styles/`; вложенные
папки более глубокого уровня профилями не считаются.

В примерах ниже путь к папке профиля указан относительно `resources/`, а
значения файловых параметров в `config.cfg` — относительно папки профиля.

## Структура профиля

Минимальный профиль:

```text
styles/
└── my-gost/
    ├── config.cfg
    └── reference.docx
```

Полный профиль (на примере `GOST_7.32-2017`):

```text
styles/
└── GOST_7.32-2017/
    ├── config.cfg
    ├── GOST_7.32-2017.docx
    ├── GOST_7.32-2017.lua
    ├── GOST_7.32-2017.yaml
    ├── GOST_7.32-2017.md
    ├── GOST_7.32-2017.ai.md
    └── tools/
        └── build_gost.py
```

Reference DOCX профиля может создаваться скриптом-генератором, например:

```bash
python "resources/styles/GOST_7.32-2017/tools/build_gost.py"
```

## Файл `config.cfg`

Формат — строки вида `ключ=значение` в кодировке UTF-8. Пустые строки и
строки, начинающиеся с `#` или `;`, игнорируются. Неизвестные ключи также
игнорируются.

Полный `config.cfg` профиля `GOST_7.32-2017`:

```ini
gost_name=ГОСТ 7.32-2017
reference_docx=GOST_7.32-2017.docx
lua_filter=GOST_7.32-2017.lua
crossref_config=GOST_7.32-2017.yaml
gost_generator=tools/build_gost.py
docs=GOST_7.32-2017.md
prompt=GOST_7.32-2017.ai.md
```

### Обязательные параметры

`gost_name` — название профиля в списке программы. Если несколько профилей
имеют одинаковое название, первый (в алфавитном порядке папок) сохраняет его,
а к остальным добавляется суффикс `(1)`, `(2)` и т. д.

`reference_docx` — reference DOCX-файл с стилями, размерами страницы, полями,
шрифтами и другими параметрами оформления Word. Указывается только имя файла:
файл должен находиться непосредственно в папке профиля.

### Необязательные параметры

`lua_filter` — Lua-фильтр Pandoc для структурных преобразований документа.

`crossref_config` — YAML-конфигурация `pandoc-crossref` для подписей,
нумерации и перекрёстных ссылок на рисунки, таблицы, формулы и разделы.

`gost_generator` — скрипт, создающий reference DOCX профиля.

`docs` — документация профиля для пользователя.

`prompt` — инструкция для ИИ по подготовке Markdown-документа под этот профиль.

## Правила размещения файлов

- `reference_docx` — только имя файла в папке профиля, без каталогов.
- Необязательные файлы — относительный путь от папки профиля с разделителем `/`
  (например, `crossref_config.yaml`). Путь может вести за пределы папки
  профиля (например, к общему файлу через `../`), но обязан оставаться внутри
  `resources/`. Абсолютные пути, пути с буквой диска и разделитель `\` не
  допускаются.

## Проверка профилей

При запуске программа проверяет все папки профилей. Профиль не показывается в
списке, а в журнал выводится предупреждение, если:

- отсутствует `config.cfg` или его не удалось прочитать;
- не указан `gost_name`;
- `reference_docx` не указан, не найден или содержит путь вместо имени файла;
- указанный необязательный файл отсутствует или путь к нему выходит за
  пределы `resources/`.
